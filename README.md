# Portfolio

Personal portfolio website by Alexander Kruska -- software developer in training at Lufthansa Industry Solutions, specializing in backend development with Go and web applications with Next.js.

## Tech Stack

- Next.js 16 (App Router, static export)
- TypeScript
- Tailwind CSS 3
- react-markdown + rehype-highlight

## Setup

```bash
git clone https://github.com/n0xum/p0rtfolio.git
cd p0rtfolio/frontend
pnpm install
pnpm dev
```
